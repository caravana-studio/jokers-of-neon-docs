# Power-ups

Power-ups can be applied globally to any played hand, increasing points or multi.

Rarity determines the price of the power-up:

| Rarity   | Price |
|----------|-------|
| Common        | 100  |
| Uncommon        | 200  |
| Rare        | 350  |
| Epic        | 500  |
