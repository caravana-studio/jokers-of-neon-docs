# Power-ups

Power-ups can be applied globally to any played hand, increasing points or multi.

## Costs and Sell Values

| TIER | BASE COST | SELL VALUE |
| ---- | --------- | ---------- |
| B    | 100       | 50         |
| A    | 200       | 50         |
| S    | 350       | 100        |
| SS   | 500       | 150        |
