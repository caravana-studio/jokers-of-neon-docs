# Modifier Cards

Modifier cards have individual effects that can be applied to specific cards.

Rarity determines the price of the card:

| Rarity   | Price |
| -------- | ----- |
| Common   | 300   |
| Uncommon | 750   |
| Rare     | 1000  |
