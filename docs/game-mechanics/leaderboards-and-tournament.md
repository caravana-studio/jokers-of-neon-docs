# Leaderboards and Tournament

## Leaderboards

The game currently supports two leaderboard families.

- **Game leaderboard scopes**
  - Daily
  - Weekly
  - Season
- **XP leaderboard scope**
  - XP Season

## Game Leaderboard Rewards

### Daily

- 1st: Epic x1
- 2nd: Advanced x1
- 3rd: Basic x1

### Weekly

- 1st: Epic x1, Legendary x1
- 2nd: Epic x2
- 3rd: Advanced x1, Epic x1
- 4th-5th: Advanced x2

### Season

- 1st: Epic x2, Legendary x3
- 2nd: Epic x2, Legendary x2
- 3rd: Epic x2, Legendary x1
- 4th-5th: Advanced x1, Epic x1, Legendary x1
- 6th-10th: Advanced x1, Epic x2
- 11th-15th: Advanced x1, Epic x1
- 16th-25th: Advanced x2
- 26th-50th: Advanced x1

## XP Season Rewards

- 1st: Epic x1, Legendary x2, Collector XL x1
- 2nd: Epic x1, Legendary x2, Collector x1
- 3rd: Epic x1, Legendary x3
- 4th-5th: Epic x1, Legendary x2
- 6th-10th: Epic x1, Legendary x1
- 11th-15th: Advanced x1, Epic x1

## End-of-Season Tournament

- Runs at the end of each season
- Duration is about **10 days**
- Entry comes from season progression rewards

Tournament rewards:

- 1st: Legendary x2, Collector x1, Collector XL x1
- 2nd: Legendary x2, Collector XL x1
- 3rd: Legendary x1, Collector XL x1
- 4th-5th: Legendary x1, Collector x1
- 6th-10th: Legendary x2
- 11th-15th: Legendary x1
- 16th-25th: Epic x1
- 26th-50th: Advanced x1

Current leaderboard and tournament reward tables do **not** grant Season Pass directly.
